霍格沃茨之遗 · 特别版（macOS / Apple Silicon）
================================================================

一、怎么装
----------------------------------------------------------------
1. 双击 Hogwarts-Legacy-重建版.dmg，等待挂载（镜像约 84 GB，
   校验需要一点时间，属正常）
2. 把「Hogwarts Legacy.app」拖进左侧的「应用程序」文件夹
3. 在「应用程序」里双击打开

首次打开若提示「已损坏，无法打开，你应该将它移到废纸篓」，
这是 macOS 给下载来的 App 打的隔离标记，不是文件坏了。
打开「终端」，粘贴执行下面一行（需要输入开机密码）：

    sudo xattr -dr com.apple.quarantine "/Applications/Hogwarts Legacy.app"

之后再双击就正常了。

磁盘占用：安装后约 93 GB，请确保目标磁盘有足够空间。
卸载：把 Hogwarts Legacy.app 拖到废纸篓即可，不会残留别的东西。


二、怎么玩
----------------------------------------------------------------
双击「Hogwarts Legacy.app」→ 弹出「启动设置」面板 → 点「启动游戏」。
（也可以直接回车；想跳过面板直接进游戏，用
  open -a "Hogwarts Legacy" --args --play ）

启动流程：
  黑色窗口 →「正在准备着色器」→ 标题画面「按任意键开始」→ 主菜单

  · 第一次启动要编译着色器，可能等 5～10 分钟；
    之后热缓存约 1.5 分钟
  · 进度条长时间不动是正常的，不是卡死，别强制退出

第一次双击可能弹一个系统授权框：
「霍格沃茨之遗」想要访问可移除宗卷上的文件 → 点「允许」。
（游戏放在外置盘上时会问，装到内置盘则不会。点过一次就不再问。）


三、窗口尺寸说明（重要）
----------------------------------------------------------------
这个游戏会把自己记着的窗口尺寸强行恢复，跟启动面板里选的分辨率无关。
本版已做处理：启动器会先读出游戏上次保存的尺寸，再用它建窗，
所以**窗口从出现的第一帧起就是最终大小，不会再突然放大或缩小**。

代价是：面板里的「分辨率」下拉框不再决定窗口实际大小（游戏不认）。
想换窗口大小，请在游戏内的「设置 → 显示」里改，退出后下次启动会自动跟随。

本机实测锁定为 1405×790（客户区），是游戏自己认为合适的尺寸。


四、启动面板选项
----------------------------------------------------------------
  画面   分辨率 / 窗口模式 / 画质（最低·中·高）
  帧率   锁帧（不锁 / 30 / 40 / 45 / 50 / 60）+ VSync
  内存   标准 / 省内存（默认）/ 极限省内存
         压的是 Metal 显存：纹理池 1024→768→512 MB、
         内部分辨率 100→85→70%、阴影贴图 1024→512
  精简渲染  关 SSR / 体积雾 / 景深 / 动态模糊 / 各向异性
  启动   Metal HUD（右上角显示帧数）/ Wine 日志（排查用，会掉帧）
         屏蔽驱动警告（默认开）/ 鼠标锁定（默认开）/ CPU 拓扑

面板设置存在：
  ~/Library/Application Support/MacNativeGames/HOGWARTS/launcher-settings.json


五、鼠标锁定（游戏内按 0 切换）
----------------------------------------------------------------
默认就是锁定的：光标锁在游戏窗口内，不显示、不会飘出去点到别的 App，
镜头照常能转。按 0 可以放开鼠标，再按 0 锁回去。

注意：游戏运行期间 0 这个键会被系统占用（热键是全局注册的）。
不想要这个功能，到面板里取消「鼠标锁定」即可。
游戏退出时会自动解锁，不会把鼠标锁死。

日志：~/Library/Logs/HogwartsLegacy-mouse.log


六、存档在哪
----------------------------------------------------------------
存档在 App 内部（自包含，搬走 App 就带着存档）：
  Hogwarts Legacy.app/Contents/SharedSupport/prefix/drive_c/
  users/wilkins-/AppData/Local/Phoenix/Saved/SaveGames/

镜像内已包含原机的存档（约 11 MB）。如果要把这个包发给别人，
介意的话可以先把 SaveGames 里的内容删掉再拷贝。

Mod 放在（当前为「已停用」状态）：
  .../drive_c/Hogwarts Legacy Complete/Paks_mods_disabled/
把需要的 .pak/.ucas/.utoc 挪到同级的 Paks/ 目录即可启用。


七、已知情况
----------------------------------------------------------------
· 不会弹「显卡驱动版本过低」警告 —— 启动器把厂商伪装成 AMD，
  游戏只对 NVIDIA 做版本检查，直接跳过。渲染正常。
· CPU 拓扑请保持「4 个性能核（默认）」，选全部 10 核实测会崩。
· 音频、手柄未做特殊适配，建议用键鼠。
