# 游戏台

macOS 上通过 Wine / MacNativeGames 运行 Windows 游戏的**构建脚本与实操文档**集合。仓库只放文档和脚本，不含游戏本体、存档和 MOD。

## 这里有什么

| 路径 | 内容 |
|---|---|
| `游戏构建/总重建指引.md` | 从零重建的总流程，先读这份 |
| `游戏构建/<游戏>-重建实操指引.md` | 各游戏的重建步骤与踩坑 |
| `游戏构建/<游戏>/_build/` | 部署、清理、体检脚本 |
| `霍格沃茨之遗/文档/` | MOD 制作过程留档（成功与失败） |
| `_脚本/` | 打包到硬盘 / 网盘的辅助命令 |

目前覆盖 6 个游戏：塞尔达、MilkGame、霍格沃茨之遗、鬼泣4、港诡实录、虐杀原形。

## 怎么用

1. 先读 [`游戏构建/总重建指引.md`](游戏构建/总重建指引.md)，确认工具链（Wine / MacNativeGames / 打包脚本）齐全。
2. 再按对应游戏的「重建实操指引」逐步执行，`_build/` 里的脚本可直接运行。
3. 遇到白窗口、崩溃、图标缺失等问题，先查对应指引的「踩坑」一节。

## 仓库边界

- **游戏本体不入库**：都放在外置硬盘 `/Volumes/SSD/Game/`，仓库里只有路径说明。
- **存档与 MOD 不入库**：`.gitignore` 已排除 `存档备份/`、`mods备份/` 和 `.sav` / `.pak` / `.ucas` / `.utoc`。
- **Wine prefix 不要删**：在 `~/Library/Application Support/MacNativeGames/` 下，删了存档和配置一起没。
- **App 路径不要含中文**：中文路径会导致白窗口或直接崩溃，迁移时保持纯英文路径。
- `游戏构建/` 的结构由同步脚本生成，不要手动改层级，否则下次同步会错位。

## 说明

- 文档来自个人实践，macOS 版本、芯片和游戏版本不同，步骤可能需要微调。
- 不提供游戏本体或破解资源，仅记录本机运行环境的重建方法。
- 反馈：GitHub Issues。
